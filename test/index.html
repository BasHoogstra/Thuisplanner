Welkom bij jullie Huisplan

Om de planner live te delen, gebruik je een gratis Firebase-database. Eenmalig (~5 min):

  1. Ga naar console.firebase.google.com en log in.
  2. Klik "Project toevoegen" → naam invullen → aanmaken.
  3. Links: Build → Realtime Database → Database aanmaken.
  4. Kies regio → "Beginnen in vergrendelde modus" → Inschakelen.
  5. Tabblad Regels: vervang alles door de regels hieronder → Publiceren. (Niet de testmodus gebruiken: die stopt na 30 dagen en laat iedereen alles lezen.)
  6. Kopieer de database-URL (bijv. https://naam-rtdb.europe-west1.firebasedatabase.app).

🔒 Beveiliging

Nog niet gecontroleerd

De link naar jullie planner werkt als wachtwoord. Met deze Firebase-regels kan niemand de lijst met alle planners opvragen, en verlopen de regels niet (de testmodus van Firebase stopt na 30 dagen).

Zo stel je de regels in
  1. Open de Firebase Console → jullie project.
  2. Build → Realtime Database → tabblad Regels.
  3. Vervang alles door de regels hieronder en klik op Publiceren.
