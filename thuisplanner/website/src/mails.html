Welke mails sturen wij?

Thuisplanner stuurt alleen mails die nodig zijn om de app te gebruiken. Geen reclame en geen nieuwsbrieven. De mails komen van het domein mail.mijnthuisplanner.nl.

Je inlogcode

Als je inlogt, krijg je een mail met een code van zes cijfers. De code is 10 minuten geldig en werkt maar één keer. De code staat nooit in het onderwerp van de mail.

Een uitnodiging

Als iemand je uitnodigt voor zijn of haar huishouden, krijg je een mail met de naam van wie je uitnodigt. In die mail staat geen link die je zonder inloggen toegang geeft. De uitnodiging zie je pas als je inlogt met het adres waarop je bent uitgenodigd.

Een nieuw e-mailadres bevestigen

Als je je e-mailadres wijzigt, krijg je een code op je oude én op je nieuwe adres. Pas als beide kloppen, verandert je adres.

Herken een echte mail

  • Wij vragen nooit om een wachtwoord; Thuisplanner gebruikt geen wachtwoorden.
  • Wij vragen je nooit om je code aan iemand te geven, ook niet aan ons.
  • Krijg je een code die je niet hebt aangevraagd? Dan kun je de mail negeren. Zonder de code kan niemand inloggen.
